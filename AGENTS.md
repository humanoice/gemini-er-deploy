# Overview
This is the roboparty deploy repository that we modify to integrate Google Gemini ER API and camera Realsense d435i. 

Our goal is to command the robot in text prompt and it will perform the action using the camera and the Gemini ER API for enhanced perception and interaction.

End goal is to say "walk to the chair" and the robot will use its camera to identify the chair, navigate towards it, and stop when it reaches the chair.
